# docs — the template's own guide

**Why** — `README.md` holds the landing page and the setup prompt; the detail lives here so no
page passes the 12,000-character ceiling.

**Load it when** — you are using or extending the template, not installing it.

| File | Holds | Open when |
|---|---|---|
| `using.md` | setup output, daily use, the changelog, token economy, lanes and gates | working day to day |
| `inside.md` | the skill, adding a rule, staying current, what is deliberately absent | changing the kit or upgrading |
