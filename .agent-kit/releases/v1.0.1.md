# Release v1.0.1

**Date:** 2026-10-28

### Added

- the release rule says who picks the number, and v1.0.0 is cut (TASK-111)
- prompts have their own folder, and AGENTS.md has a trim pass (TASK-113)
- the files a session reads before it plans now have a cap, and doctor fails past it (TASK-115)
- a kit review finds the rule that costs two sessions, then fixes or proposes it (TASK-116)
- the three kit-review limits are decided in the backlog, so a later session does not re-open them (TASK-118)
- "upgrade agent-kit" has a procedure: check the source, show the diff, pull as one task (TASK-119)
- a release gets its tag automatically, and the tag message is the release note (TASK-121)

### Changed

- the release procedure lives in its own rule file, one pointer in the loop (TASK-112)
- the trim moves each fact to its home and wires the pointer that reaches it (TASK-114)
- a template change is judged by the install it reaches, not by this repo's tidiness (TASK-117)
- an install follows a release tag, so it never receives unreleased commits and can pick its version (TASK-120)

### Fixed

- a quoted task summary no longer leaks YAML escapes into the release note (TASK-122)
- release --tag reads its version from the flag, so the documented command runs (TASK-123)
- a release tag keeps the note's headings, so the whole note reaches the reader (TASK-124)
