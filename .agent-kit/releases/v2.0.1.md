# Release v2.0.1

**Date:** 2026-11-04

Corrects the v2.0.0 note shape: categorized entries, each with its commit link. No install
surface changed in this release.

### Added

**Commit shape gate** ([170cc2e](https://github.com/AbdulWadudh/agent-kit/commit/170cc2e))
The pre-commit guard caps a commit at 20 staged files (`K79_ALLOW_BULK=1` is the deliberate
exception), warns above three concerns, and keeps the task write-set check. `agent-kit guard plan`
prints one `git add -- <paths>` line per concern. The commit-msg guard requires `Why:`, `What:` and
`Verification:`; it warns by default and blocks with `K79_GUARD=strict`.

**k79 engineering rules and examples** ([170cc2e](https://github.com/AbdulWadudh/agent-kit/commit/170cc2e))
Code structure and splitting, verification, errors and logging, configuration, security,
performance, database safety and testing now have rule files and copyable rule examples, with
`doctor` checks where a check exists.

**Nine `k79-*` skills and the project install** ([170cc2e](https://github.com/AbdulWadudh/agent-kit/commit/170cc2e))
Commit, release, debug, spec, prompt craft, docs populate, kit review, trim AGENTS and upgrade live
in `.agent-kit/skills/`. `agent-kit prompt` prints any of them; `agent-kit skills install` publishes
all nine into the project's `.agents/skills`; `agent-kit wire` writes optional native pointers.

### Changed

**The task file is the only per-task record** ([170cc2e](https://github.com/AbdulWadudh/agent-kit/commit/170cc2e))
`task close` archives the task and writes no change card. `release` derives its note from unclaimed
archived tasks, and `start` lists the newest archived tasks.

**The baseline is a commit SHA, not a table** ([170cc2e](https://github.com/AbdulWadudh/agent-kit/commit/170cc2e))
`task new` records `baseline:` and no longer runs the suite. `verify` writes one evidence table;
`--baseline` is gone.

**Setup asks eight questions** ([35f7794](https://github.com/AbdulWadudh/agent-kit/commit/35f7794))
The README now asks harnesses, task ids, the commit guard, native `/k79-*` wiring, project skill
install, off-limits paths, the first task, and the optional external skills.

**The dedicated prompt skill is `k79-prompt-craft`** ([4f42751](https://github.com/AbdulWadudh/agent-kit/commit/4f42751))
It replaces the `prompt-master` recommendation; `rtk` owns token economy, so `caveman` is no longer
recommended.

### Removed

**Logs and change cards** ([170cc2e](https://github.com/AbdulWadudh/agent-kit/commit/170cc2e))
`.agent-kit/logs/` is no longer installed or written. Legacy cards remain readable by `release`
during an upgrade.

**The baseline table and run** ([170cc2e](https://github.com/AbdulWadudh/agent-kit/commit/170cc2e))
There is one evidence table and no second, identical baseline table.

**Selftest from target installs** ([170cc2e](https://github.com/AbdulWadudh/agent-kit/commit/170cc2e))
The 17-file selftest suite is template-only; a target repo prints a clear "not shipped" message.

**The `prompt-master` and `caveman` recommendations** ([4f42751](https://github.com/AbdulWadudh/agent-kit/commit/4f42751))
They duplicated the bundled prompt skill and `rtk`.

## Migration

- Existing installs keep their old cards readable; new closes write no card.
- `project.md` is owned, so add `## Source roots` and `## Test roots` by hand or the structure
  checks stay dormant.
- Install the repo skills in the project, never globally: `agent-kit skills install`.
- Re-run `agent-kit wire` to create native `/k79-*` pointers.
