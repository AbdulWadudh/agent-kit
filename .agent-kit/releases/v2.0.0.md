# Release v2.0.0

**Date:** 2026-11-04

### Added

**Task-only state, k79 rules, nine skills and the commit gate** ([170cc2e](https://github.com/AbdulWadudh/agent-kit/commit/170cc2e))
The task file is the only per-task record: `task close` archives it and `release` derives notes from
archived tasks. The baseline is a commit SHA, not a table. Code structure, verification, errors and
logging, configuration, security, performance, database safety and testing now have rule files and
copyable examples with `doctor` checks where a check exists. Nine `k79-*` source skills ship in
`.agent-kit/skills/`; `agent-kit skills install` publishes them into the project's `.agents/skills`,
and `agent-kit prompt` prints any of them. The commit gate caps a commit at 20 staged files
(`K79_ALLOW_BULK=1` is the deliberate exception), prints a `guard plan`, and requires
`Why/What/Verification` on the body, blocking only with `K79_GUARD=strict`.

The same commit removes the `logs/` change-card ledger and the duplicate baseline table. The
17-file selftest suite is template-only in target installs.

### Changed

**Eight setup questions and project skill install** ([35f7794](https://github.com/AbdulWadudh/agent-kit/commit/35f7794))
The README setup prompt asks harnesses, task ids, the commit guard, native `/k79-*` wiring, project
skill install, off-limits paths, the first task and optional external skills. `SETUP.md` and
`setup/3-skills.md` document the same eight answers, and `--wire` is the opt-in that creates a
harness folder and its pointers.

**The dedicated prompt skill is `k79-prompt-craft`** ([4f42751](https://github.com/AbdulWadudh/agent-kit/commit/4f42751))
`k79-prompt-craft` replaces the `prompt-master` recommendation, and `rtk` owns token economy, so
`caveman` is no longer recommended. The source and generated skill were renamed from
`k79-task-brief`.

## Migration

- Existing installs keep their old cards readable: `release` reads legacy cards without duplicating
  an archived task. New closes write no card.
- `project.md` is `owned`, so `pull` does not add `## Source roots` or `## Test roots`. Add both (and
  `## Structure exceptions` if needed) or the structure checks stay dormant.
- Install the repo skills in the project, never globally: `agent-kit skills install`.
- Re-run `setup` or `agent-kit wire` to create native `/k79-*` pointers.
