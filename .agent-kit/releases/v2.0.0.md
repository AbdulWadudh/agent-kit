# Release v2.0.0

**Date:** 2026-11-04

### Added

- **Commit shape gate.** `agent-kit guard plan` groups staged files by concern, prints a
  `git add -- <paths>` line per group, and flags any group over the cap. The pre-commit guard
  refuses more than 20 staged files (`K79_ALLOW_BULK=1` is the deliberate exception), warns above
  three concerns, and keeps the task write-set check. The commit-msg guard requires `Why:`,
  `What:` and `Verification:`; it warns by default and blocks with `K79_GUARD=strict`.
  `K79_SKIP_GUARD=1` is the emergency bypass.
- **k79 engineering rules.** Code structure and splitting, verification, errors and logging,
  configuration, security, performance, database safety and testing now have rule files and
  rule examples. The rules carry executable `doctor` checks where a check exists.
- **Invokable `k79-*` skills.** Nine source skills in `.agent-kit/skills/`: commit, release,
  debug, spec, prompt craft, docs populate, kit review, trim AGENTS, upgrade. `agent-kit prompt`
  prints any of them; `agent-kit wire` writes optional native pointers; `agent-kit skills install`
  publishes all nine into the project's `.agents/skills`.
- **`agent-kit skills`.** `build`, `check` and project-only `install` turn the source skills into
  normal installable skills.

### Changed

- **The task file is the only per-task record.** `task close` archives the task; it writes no
  change card. `release` derives the note from unclaimed archived tasks and claims task ids.
  `start` lists the newest archived tasks.
- **The baseline is a commit SHA, not a table.** `task new` records `baseline:` and does not run
  the suite. `verify` writes one evidence table. `--baseline` is gone.
- **Setup asks eight questions**, including the repo-skill install, and `--wire` is the opt-in
  that creates a harness folder and its native pointers.
- **Code structure and verification are gates**, not advice: source caps, folder density, feature
  barrels, test mirroring and declared roots have `doctor` rows and `selftest` cases.

### Removed

- `.agent-kit/logs/` and the change-card model, including its writer and the logs seed.
- The `## Baseline` block and the baseline run.
- `.agent-kit/lib/selftest/` from target installs; `selftest` is template-only.
- The `prompt-master` and `caveman` recommendations; `k79-prompt-craft` owns prompt building and
  `rtk` owns token economy.

## Migration

- Existing installs keep their old cards readable: `release` reads legacy cards without
  duplicating an archived task. New closes write no card.
- `project.md` is `owned`, so `pull` does not add `## Source roots` or `## Test roots`. Add both
  (and `## Structure exceptions` if needed) or the new structure checks stay dormant.
- Install the repo skills in the project, never globally: `agent-kit skills install`.
- Re-run `setup` or `agent-kit wire` to create native `/k79-*` pointers.
