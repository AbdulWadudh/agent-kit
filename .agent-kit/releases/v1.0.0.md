# Release v1.0.0

**Date:** 2026-10-28

### Added

- setup writes the harness skill pointer for a harness whose folder the repo already keeps (TASK-109)

### Changed

- The workflow runs itself (TASK-101)
- one command for session state, tiered verify, blocked tasks, close artifacts (TASK-103)
- subtasks close quick with lint; the main task runs build at close (TASK-104)
- a changelog entry carries the task summary, and each version gets a release file (TASK-105)
- a session pays for characters, not lines (TASK-106)
- commit conventions and skill sources leave the always-read rule file (TASK-107)
- every installed path lives under .agent-kit, except the three a harness pins to a fixed location (TASK-108)

### Removed

- the CI workflow is gone, and the commit guard is executable on every clone (TASK-110)
