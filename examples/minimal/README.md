# Example: what "filled" looks like

Not installed, not copied, not checked by `doctor`. It exists so you can see the target of
the fill work in `SETUP.md` step 2 without guessing.

A real install differs in one way: `setup` writes your `AGENTS.md` from the seed, and you
replace the markers. This is that file afterwards, for a fictional notes API.

| File | Shows |
|---|---|
| `AGENTS.md` | markers replaced, rules 1-4 written for a real repo, kit section kept verbatim |
| `.agents/project.md` | the generated table with the commands confirmed by a human |
| `src/index.ts` | the file the example rules talk about |
