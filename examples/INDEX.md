# examples — what a set-up repo looks like

**Why** — a filled example answers "is my install finished?" faster than any checklist.

**Load it when** — you want to compare a real install against a finished one. This folder is
not installed into a target repo and receives no updates.

| Path | Holds | Open when |
|---|---|---|
| `minimal/` | a fictional repo right after setup: `AGENTS.md` and `.agent-kit/project.md` filled, one source file | comparing shapes |

Open `examples/minimal/AGENTS.md` first. The rest is the example's own tree, not a template to
copy file by file.
