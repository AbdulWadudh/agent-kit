# 📘 TypeScript & Code Style Rules

1. **Explicit Types**: Never use `any`. Use explicit interfaces, types, or `unknown`.
2. **Named Exports**: Always use named exports (`export const myFunc`). Avoid default exports.
3. **Strict Null Checks**: Handle `null` and `undefined` explicitly.
4. **Imports**: Import only necessary functions/types. Verify path existence in `docs/ARCH_MAP.md`.
